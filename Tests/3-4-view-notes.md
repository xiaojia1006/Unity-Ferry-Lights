# 3/4 斜俯视编辑说明

项目仍使用 XY 平面、方形 Tilemap 和正交摄像机。立体感来自现有的树木、房屋与台阶贴图，以及落地点遮挡。

- `ObliqueDepth2D`：角色、NPC、建筑、宝箱和物品的排序组件。可以指定 `Feet` 空物体作为落地点；未指定时优先取实体碰撞体底边。`Foot Offset` 可微调排序接触点，不移动贴图。`Elevated` 表示高台层。
- `ObliqueTilemap2D`：原 Tilemap 的可视投影。树冠、树干使用 Tree 图集三行一棵树的根部深度排序。继续在原 Tilemap 绘制；投影只影响显示，不替换原瓦片数据与碰撞。该 Tree 图集的布局改变时，应同步修改 `RootOffset`。
- 地形 Order 按原顺序扩为 1000 倍，以容纳动态排序。地面角色在约 5000，高台角色在约 15000。新加的普通物体应挂 `ObliqueDepth2D`，不要再手动写角色的 Sorting Order。
- 高台入口/出口切换 `Elevated`，保留原有边界碰撞开关。离开场景时持久玩家的高台状态重置。
- 河道和现有地面不重画；不改变摄像机旋转、贴图 Pivot 或物体位置。
- 首次安装只收窄角色/房屋已有的 Box 或 Capsule 实体碰撞体，保留原底边。触发器和树木瓦片碰撞不修改。战斗命中范围仍需按实际玩法调节。
- 运行时新掉落的 Loot 与箭矢自动安装深度排序；新增的自定义动态 NPC/敌人预制体也应带 `ObliqueDepth2D`。

`Tools > RPG > Apply 3-4 View` 可给当前 RPG1/RPG2 场景补齐组件。它不会自动保存场景。编辑场景中的配置确认后正常保存即可。

`Tools > RPG > Check 3-4 View` 运行隔离对象检查，结果位于 `Logs/ObliqueView2DChecks.txt`，覆盖地面前后关系、高台层、脚底位置、触发器保持、重复安装、树木根部和原瓦片碰撞。
