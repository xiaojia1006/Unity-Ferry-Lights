# 雪景制作与编辑

已接入晴/雨/雪随机系统：现在请用同对象上的 `Weather Cycle 2D > Current Weather = Snow` 预览雪景；运行中默认随机切换。完整控制见 `Tests/weather-cycle-notes.md`。

适用条件：Unity 2021.3 内置管线、XY 平面 Sprite/Tilemap、正交相机、当前 Tree/House 图集和 3/4 落地点排序。没有引入 URP、3D 地形或改变摄像机角度。

场景中的 `Winter Weather` 对象控制天气：

- `Snow Coverage`：积雪覆盖度，默认 0.9；调低可露出更多草地。
- `Snowfall`：飘雪数量，0 表示停止产生新雪花；已有雪花随生命周期消失。
- `Wind`：横向风速，负值向左。
- `Shore Ice`：近岸装饰薄冰，河心保持流动。
- `Preview In Editor`：编辑模式预览开关。关闭它仅影响编辑模式。
- 禁用 `WinterWeather2D` 组件可恢复原有场景材质和河水效果，天气组件不会自动重新启用。

草地积雪、压实道路、枝叶亮面积雪及屋顶积雪通过像素材质实现，保留原图透明轮廓和明暗层次。树木动画仍使用原帧；角色、宝箱、掉落物和商家金币不使用积雪材质。材质按现有图集颜色识别表面，新美术应单独检查配色和顶面范围。

雪花为三层有上限的 ParticleSystem，使用世界坐标并跟随主摄像机补充发射区域。排序为 24000～24002，位于人物/高台之后绘制、商家提示 30000 之前绘制，不设置碰撞，也不阻挡 UI 点击。编辑器预览上限 20 次/秒，运行时使用游戏时间，暂停游戏也会暂停飘雪。

近岸薄冰只是装饰，不可视为可行走冰面；它保留河道遮罩、触发器和原涉水减速。没有添加滑行、冰面阻挡、足迹、音效或伤害机制。

RPG1、RPG2 打开时会自动补齐天气对象。没有自动保存用户场景，确认效果后正常保存。构建所需材质已放入 Assets/Resources，着色器有显式材质引用。

检查：`Tools > RPG > Check Winter Weather`；结果在 `Logs/WinterWeather2DChecks.txt`。检查材质引用/编译、关闭天气恢复、商家图标保留、树木与屋顶分类、河道遮罩和碰撞保持。
