# 渡口灯火 · Ferry Lights

《渡口灯火》是一部使用 Unity 制作的 2D 像素风治愈 RPG：在苇岸渡口修桥、点灯、钓鱼、煮汤。项目包含登录、探索、采集、钓鱼、烹饪、战斗、委托、昼夜和天气系统，适合作为 Unity 2D 游戏开发学习与作品展示项目。

## 项目特色

- **多场景冒险**：登录界面、RPG1 边境区域、RPG2 苇岸渡口和 Willowreach 世界。
- **探索与互动**：与 NPC、告示牌、营火、旅舍、信标、宝箱和环境物体互动。
- **完整任务链**：RPG2 包含热汤、修桥、三盏信标和遗迹宝藏四个连续委托，任务条件、材料消耗和奖励会真实结算。
- **真实属性系统**：生命、攻击、移速、体力、负重、钓鱼、烹饪、声望、射程和击退会显示在原有属性 UI 中，并影响实际玩法。
- **钓鱼玩法**：浮标只能落在真实河面，陆地位置会被拒绝；成功收鱼才会增加钓鱼熟练度。
- **战斗与昼夜**：夜晚敌人攻击力增加 3 点，玩家攻击力降低 2 点；营火、信标和旅舍会提供暖色照明。
- **天气效果**：支持晴天、雨天和雪天，并与环境音、脚印和水面效果联动。
- **全局设置**：F10 打开设置，可调整音量、画面、移动方式、昼夜模式和账号切换。
- **本机账号服务**：提供本机注册与登录服务，账号数据保存在本机服务数据库中。

## 运行项目

1. 使用 Unity `2021.3.45f2c1` 打开项目。
2. 打开 `Assets/Scenes/Login.unity`，从登录场景开始运行。
3. 如果使用账号功能，先启动 `Server` 目录下的本机账号服务。
4. 登录后按场景提示探索世界。

Unity 项目主场景构建顺序为：

`Login → RPG1 → RPG2 → Willowreach`

## RPG2 苇岸渡口流程

1. 在营火旁查看告示牌并接受热汤委托。
2. 采集 3 个蘑菇和 2 个南瓜，回到营火交付。
3. 收集 3 捆木料，在断桥处修复渡桥。
4. 按“水边 → 遗迹 → 林地”的顺序点亮信标。
5. 击败四名巡逻守卫，在西北遗迹开启宝藏。

任务奖励会根据任务内容发放金币、经验和物品；背包空间不足时会保留任务材料和奖励状态。

## 账号与数据

- 登录密码通过本机服务进行验证，游戏只在当前运行会话保存登录令牌。
- 钓鱼、烹饪和任务声望按账号隔离保存在本机 PlayerPrefs 中。
- Unity 缓存、构建产物、运行日志和本机账号数据库不会提交到 Git。
- 角色、背包、任务与世界进度按账号自动保存到本机；登录后恢复最后场景。保留备份用于坏档恢复。
- 本机服务不可连接时，按提示再次点击进入世界可用独立游客身份试玩；临时增益与进行中的动作不跨读档保留。

## 目录说明

- `Assets/Scenes`：游戏场景。
- `Assets/scrpits`：运行时脚本（目录名保持项目现有拼写）。
- `Assets/Resources`：运行时加载的 UI、天气、音频和夜景资源。
- `Assets/Editor`：场景构建、检查和自动化验证工具。
- `Server`：本机账号服务。
- `Docs`：系统设计、修复记录和测试说明。
- `Tests`：逻辑测试和回归检查。

## 开发说明

项目采用 Built-in Render Pipeline，夜景使用相机后处理和程序化光照，没有迁移到 URP。原有像素风 UI、地图素材和场景布局会被保留，新增功能优先接入现有组件。
