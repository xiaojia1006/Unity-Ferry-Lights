## 1. ★ 背包堆叠合并

**题目**：给一个固定长度的格子数组，实现 `AddItem(ItemSO item, int count)`，返回没能放进去的数量。要求：先补已有同类格（不超过 `stackSize`），再占用空格，都不够就返回剩余。

```csharp
public int AddItem(ItemSO item, int count) { /* ... */ }
```

**考察**：边界（count=0、stackSize=0）、不产生负数、返回语义。  
**提示**：两趟循环，第一趟补栈、第二趟开新格。  
**参考**：

```csharp
int left = count;
foreach (var s in slots)
    if (left > 0 && s.itemSO == item && s.quantity < item.stackSize) {
        int add = Mathf.Min(left, item.stackSize - s.quantity);
        s.quantity += add; left -= add; s.UpdateUI();
    }
foreach (var s in slots)
    if (left > 0 && s.itemSO == null) {
        int add = Mathf.Min(left, item.stackSize);
        s.itemSO = item; s.quantity = add; left -= add; s.UpdateUI();
    }
return left;
```

## 2. ★★ 可复用的冷却计时器

**题目**：写一个 `Cooldown` 结构，支持 `TryUse()`、`Remaining`、`Progress`。要求受 `Time.timeScale` 影响（暂停时冷却不走）。

**考察**：时间基准选择、暂停语义、值类型 vs 引用类型。  
**提示**：用 `Time.time` 而不是 `Time.unscaledTime`，因为这是游戏内冷却。  
**参考**：

```csharp
public struct Cooldown {
    float end, length;
    public bool Ready => Time.time >= end;
    public float Remaining => Mathf.Max(0, end - Time.time);
    public float Progress => length <= 0 ? 1 : 1 - Mathf.Clamp01(Remaining / length);
    public bool TryUse(float seconds) {
        if (!Ready) return false;
        length = seconds; end = Time.time + seconds; return true;
    }
}
```

## 3. ★★ 委托状态机

**题目**：一条委托有 `未接 / 进行中 / 可交付 / 已完成` 四个状态。写出状态迁移函数，要求：**已完成不能再接**、**材料不足不能交付**、**交付后不能重复领奖**。

**考察**：状态穷举、防止重复发放、单一数据源。  
**提示**：不要用多个 bool（`accepted` / `done` / `claimed`）拼状态，容易互相矛盾——这正是你现在 `accepted[4]` + `SuppliesDelivered` 的隐患。  
**参考**：

```csharp
enum QuestState { Idle, Active, Ready, Done }
QuestState Next(QuestState s, bool hasMaterials) => s switch {
    QuestState.Idle   => QuestState.Active,
    QuestState.Active => hasMaterials ? QuestState.Ready : QuestState.Active,
    QuestState.Ready  => QuestState.Done,
    _                 => QuestState.Done
};
bool CanDeliver(QuestState s, bool hasMaterials) => s == QuestState.Ready && hasMaterials;
```

## 4. ★★★ 存档的版本迁移

**题目**：`SaveData` 现在 `version = 1`，未来字段会增加。写出 `Load(json)`，要求：**version 小于当前值时补默认值**，大于当前值时拒绝加载并提示。

**考察**：向后兼容、默认值、不破坏旧档。  
**提示**：`JsonUtility` 缺字段会留默认值，所以关键是版本号判断 + 迁移函数表。  
**参考**：

```csharp
const int CurrentVersion = 2;

SaveData Load(string json) {
    var data = JsonUtility.FromJson<SaveData>(json);
    if (data == null) return null;
    if (data.version > CurrentVersion) return null;           // 新版本存档，旧程序不认
    if (data.version < 2) { data.stamina = 100f; data.version = 2; }  // v1→v2 补体力
    return data;
}
```

## 5. ★★ 箭矢对象池

**题目**：箭矢每 0.5 秒可能发一支，命中即销毁。用对象池实现 `Get()` / `Release()`，避免频繁 `Instantiate/Destroy`。要求池满时**复用最老的一支**。

**考察**：池化、GC、容器选择。  
**提示**：`Queue<Arrow>` 或 `Stack`；命中的箭放回要重置速度和计时。  
**参考**：

```csharp
readonly Queue<Arrow> pool = new();

Arrow Get() {
    var a = pool.Count > 0 ? pool.Dequeue() : Instantiate(prefab).GetComponent<Arrow>();
    a.gameObject.SetActive(true); a.ResetState(); return a;
}
void Release(Arrow a) {
    a.gameObject.SetActive(false);
    if (pool.Count < maxPool) pool.Enqueue(a); else Destroy(a.gameObject);
}
```

## 6. ★★★ 类型安全的事件总线

**题目**：实现 `EventBus`，支持 `Subscribe<T>(Action<T>)` / `Publish<T>(T)` / `Unsubscribe<T>`，要求**不装箱**、能防止订阅泄漏。

**考察**：泛型、静态字典、委托管理。  
**提示**：`Dictionary<Type, Delegate>`，`Publish` 时 `as Action<T>`。  
**参考**：

```csharp
public static class EventBus {
    static readonly Dictionary<Type, Delegate> map = new();
    public static void Subscribe<T>(Action<T> cb) {
        map.TryGetValue(typeof(T), out var d);
        map[typeof(T)] = Delegate.Combine(d, cb);
    }
    public static void Unsubscribe<T>(Action<T> cb) {
        if (!map.TryGetValue(typeof(T), out var d)) return;
        var n = Delegate.Remove(d, cb);
        if (n == null) map.Remove(typeof(T)); else map[typeof(T)] = n;
    }
    public static void Publish<T>(T evt) {
        if (map.TryGetValue(typeof(T), out var d) && d is Action<T> a) a(evt);
    }
}
```

## 7. ★★ 最近交互点查询

**题目**：场景有 25 个交互点，每帧找离玩家最近且在半径内的一个。写出 O(n) 版本，再说明 500 个点时怎么优化。

**考察**：距离计算、平方比较、空间分区。  
**提示**：比较 `sqrMagnitude` 避免开方；优化用网格分桶（只查玩家所在格及相邻 8 格）。  
**参考**：

```csharp
int Nearest(Vector2 p, float radius) {
    int best = -1; float bestSqr = radius * radius;
    for (int i = 0; i < points.Length; i++) {
        var d = ((Vector2)points[i].transform.position - p).sqrMagnitude;
        if (d < bestSqr) { bestSqr = d; best = i; }
    }
    return best;
}
```

## 8. ★★ 连按窗口状态机（钓鱼收线）

**题目**：咬钩后要求 3 次按键，每次间隔 ≤ 0.9 秒，超时判失败。写出状态推进函数，并说明如何避免“两次按键在同一帧被算两次”。

**考察**：时间窗、输入去重、状态复位。  
**提示**：记录 `lastPressTime`，用 `Time.time - lastPress > window` 判失败。  
**参考**：

```csharp
int taps; float deadline;
bool Tick(float window, bool pressed) {
    if (Time.time > deadline) return false;         // 超时
    if (pressed) { taps++; deadline = Time.time + window; }
    return taps >= 3;
}
```

## 9. ★ 昼夜颜色插值

**题目**：用 `Mathf.Lerp` 在“白天色”和“夜色”之间过渡，要求 90 秒内完成，且用平滑曲线（不要匀速）。

**考察**：插值、缓动、把时间归一化。  
**提示**：`Mathf.SmoothStep(0,1,t)` 比 `Lerp` 更自然；`t = elapsed / duration`。  
**参考**：

```csharp
float t = Mathf.Clamp01(elapsed / 90f);
float k = Mathf.SmoothStep(0f, 1f, t);
var color = Color.Lerp(dayColor, nightColor, k);
```

## 10. ★★ 权重掉落

**题目**：给定 `{蘑菇:3, 南瓜:2, 骨头:1}`，写一个按权重随机取一个的函数。

**考察**：概率、边界、可复现（种子）。  
**提示**：累加总权重，随机 `[0, total)`，再顺序扣减。  
**参考**：

```csharp
T Pick<T>(IList<(T item, int weight)> list, System.Random rng) {
    int total = 0; foreach (var e in list) total += e.weight;
    int roll = rng.Next(total);
    foreach (var e in list) { roll -= e.weight; if (roll < 0) return e.item; }
    return list[^1].item;
}
```
