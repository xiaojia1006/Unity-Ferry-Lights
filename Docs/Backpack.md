# Backpack

Open with **B** or the bottom-left **BAG [B]** button. Close with B, Escape, or X.

- 30 slots share the existing `InventortyManager.itemSlots` data. The first five are the existing HUD quick bar.
- Pickups, chest rewards and shop purchases fill existing stacks before empty slots; stack limits come from `ItemSO.stackSize`.
- Click an item to inspect it. Double-click or press USE to consume one when it has a usable effect. A healing-only item is retained at full health.
- Right-click or press DROP 1 to spawn one world item near the player. Dropping outside the grid does not destroy an item.
- Drag to move, merge compatible stacks, or exchange different items. Shift-drag transfers half a stack (rounded up); a different occupied stack rejects a split.
- SORT BAG consolidates and sorts slots 6–30, leaving the five quick bar assignments intact.
- ALL / USABLE / MATERIALS highlight matching items while preserving physical slot positions. Usability comes from the existing item effects, not invented weapon/armour categories.
- The left panel displays the current player's active SpriteRenderer layers, level, health, damage, movement speed and gold. It does not create a second gameplay player or use the shopkeeper camera.
- The game pauses while the bag is open. Other menu and nearby NPC interactions are blocked until it closes.

The UI is generated by `Assets/scrpits/Inventory&Shop/BackpackUI.cs`. Art references are editable in `Assets/Resources/BackpackTheme.asset`; these are existing project sprites and the existing TMP font. English UI labels match the current font's character coverage.

Inventory remains on the existing persistent inventory object between scenes. Disk save/load is not part of this change; ending a game session follows the project's existing reset behaviour.

In Play mode, **Tools > RPG > Check Backpack In Play Mode** validates capacity, stack overflow, split/merge/swap, sorting conservation, full-bag handling, use/drop, pause restoration, mouse raycasts and UI events. It restores the pre-test inventory and health. Report: `Logs/BackpackChecks.txt`.
