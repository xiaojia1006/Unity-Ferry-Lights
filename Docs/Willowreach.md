# 柳湾边境：试玩、编辑与回滚

场景：`Assets/Scenes/Willowreach.unity`，与 RPG1、RPG2 放在同一个文件夹。在 Unity 双击打开，按 Play 即可。也可使用 `Tools > RPG > Scene Expansion > Open Expanded Scene`。原 RPG1、RPG2 没有替换；新场景仅追加到 Build Settings，不改变原场景的启动顺序。`Assets/SceneExpansion` 保留配套素材与原场景备份。

## 地图与探索

可活动边界约 74 × 50 Unity 单位，沿用纯 XY、正交摄像机和脚底 Y 排序。西南是无敌人的村落，包含两名原商人、南瓜田、羊群和恢复营火；东南是雨露蘑菇林；东北是旧矿场；西北是风雪遗迹。环形道路连接两个过河桥，西侧有可修复的返乡渡桥。水面继续使用原项目动态水材质，岸边布置芦苇，桥上取消游泳减速，桥栏保留实体碰撞。河水始终可以涉水，捷径属于便捷奖励，不是强制的地图进度锁。

玩法：寻找三处标志牌，分别完成晴、雨、雪的观测。靠近站点可按 F1/F2/F3 选择天气，再按 E 记录。天气在 6 秒内过渡，仍会每 75–120 秒随机切换；记录判断当前目标天气，允许立即完成，不强迫等待动画。三站完成后，到遗迹南侧的断桥标记旁修复渡桥。

- WASD / 方向键：移动；J：原近战；其余装备按原设置。
- E：采集、天气观测、营火、捷径。
- K：原商店、宝箱互动。
- F1 / F2 / F3：仅在天气观测站范围内，选择晴 / 雨 / 雪，避免与原数字装备键冲突。
- Tab：探索地图及玩家位置，打开时暂停；再次 Tab / Esc 关闭。
- B：原背包；打开时隐藏探索 HUD。
- Home：回村口救援，保留当前会话探索进度、背包与金币。

奖励发放前先检查背包，满包不消耗采集点。观测、采集和捷径均防止重复领奖。敌人超出区域会返回；村口无初始战斗。地图暂停使用共享 MenuPause，不会关闭背包时误恢复其他菜单的暂停。

本关是可试玩的独立扩展场景；新采集和观测进度只在当前运行中保存，退出 Play 会重置。尚未加入跨次游戏的存档或室内关卡。羊群有独立的避水寻路和牧羊支线。场景为编辑器中实际保存的对象与 Tilemap，不依赖进游戏后临时搭出地图。

## 如何继续修改

Hierarchy 的 `Willowreach - authored world` 下：`Editable terrain` 三张 Tilemap 分别为草地、路径、路径边缘，可用 Tile Palette 直接绘制；新路径应同时修改边缘层。房屋、松树、岸边芦苇、资源点、站点和桥都是独立对象。移动站点后地图标记会随其位置生成。改变河形/道路后，`FieldMap.png` 需重新生成（目前由编辑器工具生成概略路线，不是实时渲染地形）。桥的位置变更需同步根对象 WillowreachWorld 的 Bridges 矩形，保证取消减速的范围与桥面一致。

`Polish Expanded Terrain` 是制作工具，会重建该扩展场景的地形和村落细节；手动绘图后不要执行它，以免覆盖手绘道路。`2 Build Willowreach` 拒绝覆盖已存在场景。
