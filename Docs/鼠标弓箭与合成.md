# 鼠标弓箭与骨箭合成（2026-11-25）

持弓状态下，鼠标移动决定aimX/aimY、角色水平朝向和箭矢实际方向；鼠标左键点击开始原有射击动画，动画事件释放箭。旧Shoot键不再发射。行走不覆盖持弓时的鼠标朝向。

骨箭为实体背包物品，堆叠64，每次成功发射扣1；初始不赠送无限箭。背包选中骨头后使用原USE按钮（显示CRAFT 5 ARROWS），1骨头合成5骨箭。原背包统计区域增加ARROWS总数，没有新增面板或更换UI布局/字体/底图。骨头仍保留柳湾骨笛用途，玩家自行选择如何分配。

合成先模拟扣除一骨头后的容量，放不下时原样恢复，不吞材料。箭矢通过现有资产GUID存档。射击点击有单次待发标记，真正生成箭矢时消耗；菜单/暂停/对话/商店/钓鱼时阻止请求，射击中取消不扣箭。连续动画事件不会多扣，箭命中敌人一次后销毁，避免同一箭重复伤害。

验证：Unity运行时与Editor编译通过。Logs/ArrowChecks.txt 15项检查通过：无材料拒绝、实际合成、存档目录引用、鼠标四方向映射、请求生成箭并准确扣1、重复事件不扣、暂停不扣、空箭拒绝、满包保留骨头、最后一骨头释放格子可制作。测试使用临时账号，退出试玩并清理测试存档。

测试通过公开射击请求与动画释放方法验证，尚未逐个鼠标手工试玩所有角色动画方向。配方和箭资源由Assets/Editor/ArrowWorkshop.cs初始化，箭图标复用原Arrow贴图，无新美术。未推送GitHub。

## 平滑瞄准与实际命中改进（2026-11-25）

保留当前“按住鼠标拉弓、松开鼠标放箭”操作。瞄准在LateUpdate、镜头跟随后更新；最短角度指数平滑，默认响应24，帧率独立。鼠标距角色屏幕中心12像素内保持方向，水平分量阈值0.16避免鼠标在头顶附近反复翻转。拉满弓暂停动画时间时使用零时间Animator更新保持方向姿势刷新，不推进拉弓动画。沿用现有像素方向动画，未改UI或更换素材。

箭启用连续碰撞与物理插值，每物理步沿飞行方向扫掠细碰撞体。敌人子碰撞体即使层不同，也按父Enemy_Health与其层识别；支持受击Trigger，忽略纯环境Trigger。最近墙体会先挡箭；同一箭命中一次后不会再扣血。伤害仍经NightCombat2D计算，保留无敌规则。

Logs/ArrowHitChecks.txt：8项Unity运行检查通过。实际原箭预制体以速度100在物理步路径检测中命中宽度0.03的敌人子Trigger，并确实改变Enemy_Health.currenetHealth；墙挡箭无穿墙伤害；无敌免伤；重复碰撞无二次伤害；平滑响应帧率一致与暂停不漂移。

本轮未做完整人工鼠标试玩，现有姿势仍受原方向动画帧数限制；数字与物理回归通过不等于新增了任意角度角色素材。未推送GitHub。
