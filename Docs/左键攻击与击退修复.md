# 左键攻击与致命伤击退修复（2026-11-25）

问题：Enemy_Health.ChangeHealth造成致命伤时可能同步SetActive(false)，Arrow或player_combat仍在随后调用Enemy_Knockback，导致inactive对象无法启动协程。修改为伤害调用处确认目标存活并启用，Enemy_Knockback再次验证生命与活跃状态，Awake初始化引用。OnDisable停止协程并清理速度/存活敌人的击退状态。移除knockback applied刷屏日志。

操作：剑模式左键点击攻击；弓模式维持按住左键拉弓、松开放箭，鼠标瞄准。移除PlayerMovement中Slash旧键入口。近战组件自行读取左键，检查当前武器/暂停/菜单/商店/对话/钓鱼，UI点击不触发近战。切装备明确设置互斥状态，避免两个组件一起攻击。没有改动UI布局或素材。

Unity编译通过；Logs/MouseCombatChecks.txt十项运行检查通过：近战发起、暂停屏蔽、持弓禁剑、真实近战致命击杀、inactive击退拒绝、真实箭矢致命击杀、零协程错误、存活目标击退、中断清理和测试期间无Error/Exception。测试独立账号已清理，结束退出Play。历史Console红色报错仍可能保留，但本次测试未新增该错误。未推送GitHub。
