# RPG2 夜晚模式实现与使用

## 体验

- Esc / F10 → 画面 → 苇岸昼夜：自动昼夜 / 常亮白天 / 夜晚。自动保存在当前设备。
- F9：白昼 → 黄昏 → 夜晚 → 黎明的快速预览。关闭设置并恢复游戏后使用。
- 自动模式一轮 8 分钟：白昼180秒、黄昏60秒、夜晚180秒、黎明60秒。暂停菜单同时暂停昼夜。
- 仅 RPG2 苇岸渡口参与。重新进入场景从白天开始；若设置为固定夜晚，则进入即为夜晚。

## 视觉与音频

- 夜幕采用蓝青月光、轻暗角；基础夜幕最高0.45，天气/边缘补偿后仍不超过0.50。白天直接输出原画。
- 营火暖橙照明最强，旅舍暖黄、遗迹微绿。三盏信标只有原有 glow 启用才照亮地面；点亮时0.15秒轻微提亮。
- 不更改任务、奖励、守卫数值、地图碰撞和原有素材。
- 夜间使用现有 Continue_Life，靠近遗迹宝箱8单位内使用 Lightless_Dawn，离开10单位外切回。迟滞区间防止站在边缘反复切歌。
- 黎明恢复原白天音乐。复用 GlobalSettings 原有 AudioSource，先淡出再淡入；不创建竞争的音乐播放器。音乐静音、主音量、音乐音量继续生效。
- 两首现有音乐通过 NightAudioLibrary 引用，采用流式加载，未复制大型音频文件。

## 与设计稿的实现差异

设计稿的“全屏 Overlay Canvas + 世界 Sprite 光斑”会让世界光斑始终处于夜幕下方，也不能按 sortingOrder 保护世界空间预警。因此改为 Built-in 世界相机后处理，先处理世界，再由 Unity 绘制原有 Overlay HUD。

NightAtmosphere shader 用世界节点投影的柔光池降低当地夜幕，同时叠加少量暖色。光源没有实体碰撞体，不改变 Y 深度排序；没有迁移 URP。守卫预警周围保留原画面亮度，菜单、小地图和任务 HUD 不染色。灯光为氛围照明，不含墙体遮挡或实时投影。

不使用新贴图圆片，避免灰色光圈；程序径向曲线取代 vignette.png / light_soft.png。未更改任何场景文件，进入 RPG2 时自动创建场景所属的控制器，离开销毁。

## 文件

- Assets/scrpits/DayNight2D.cs：时间、节点、天气、预警和音乐选择。
- Assets/scrpits/NightCamera2D.cs：Built-in 相机效果和材质生命周期。
- Assets/Resources/Night/NightAtmosphere.shader：夜幕、月光、暗角及暖光池。
- Assets/scrpits/NightAudioLibrary.cs / Assets/Resources/Night/Audio.asset：现有音乐构建引用。
- Assets/scrpits/GlobalSettings.cs：增加兼容旧存档的 dayNightMode 整数字段及画面选项；场景音乐借用接口。
- Assets/Editor/NightWorkshop.cs：搭建引用、运行检查与截图。

## 第二版：夜景和夜间战斗（2026-11-22）

根据实际反馈，取消灰阶混色的月光雾层，改为保留素材色彩的乘色照明与轻对比。远处树木、水面形成深冷色剪影，营火暖光范围扩大并平滑衰减；玩家脚边有很弱的可见度补偿。守卫预警仅保护实际红色像素，不再照亮预警整块矩形。

RPG2 夜间战斗：敌人每次攻击额外 +3 点（守卫 2 → 5）；玩家近战、弓箭命中伤害 -2，原本正伤害最低为1，零伤害不变。状态栏显示敌攻+3/自攻-2，背包和属性页显示实际近战攻击力。只在 Night 相位生效；白天、黄昏、黎明和离开 RPG2 后恢复。

实现使用 NightCombat2D 的命中时计算，不修改 StatsManager.damage、装备加成或敌人基础伤害，因此多次昼夜切换不会累加、恢复也不会覆盖夜间获得的升级加成。旧说明中“不改变玩法数值”的条款已由此用户要求替代。

第二版验证：Unity 编译通过；NightWorkshop 的 combat-test 运行通过。实际近战命中：基础攻击7，白天扣7 / 夜晚扣5；实际守卫命中：白天扣2 / 夜晚扣5 / 黎明扣2。反复八轮昼夜切换不改变基础攻击力；最低正伤害1与零伤害规则通过。原有夜晚光源/音乐/切换检查 test 再次通过。已在 Unity 试玩窗口检查新版夜景与夜间战斗提示。
