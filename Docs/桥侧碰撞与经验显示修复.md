# 桥侧碰撞与经验等级显示（2026-11-25）

桥：RPG2原只有桥面涉水免减速判断，缺少两侧实体阻挡。BridgeRails2D按实际木板SpriteRenderer边界生成左右BoxCollider2D，2D静态障碍层7，随修桥对象启用，桥两端开放。适配现有桥移动、缩放，不修改贴图和UI。

经验：共用Bangers字体材质FaceColor为黑色，文字在黑色经验条上不可见。ExpManager为该文字单独复制材质并设为白色，保留原字体和条的位置，恢复标签可见性，不修改其它界面的字体材质。显示Lv.N EXP 当前/升级所需。

Unity编译通过；真实角色碰撞体向桥两侧Cast均命中对应护栏，沿桥纵向不命中护栏；等级标签启用、生成15个字符，文字Lv.1 EXP 4/12，字体独立材质白色检查通过。实际截图已确认经验等级可见。Logs/BridgeExperienceChecks.txt。未推送GitHub。
