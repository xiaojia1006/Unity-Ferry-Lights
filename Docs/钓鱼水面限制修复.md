# 钓鱼水面限制修复（2026-11-24）

原因：原 ComputeCastPoint 在朝向±60度内找不到水时，退回前方3.8米固定落点，没有验证是否水面，导致陆地也能抛竿、咬钩和收鱼。

修改：TryFindFishingCast 优先朝向，再左右搜索完整360度，最大距离4.8米；无真实水面就拒绝开始，不设置钓鱼状态或冷却。落点和周围0.16米必须都在启用水面的PolygonCollider2D内；已修好的桥面排除。收鱼前再次验证，陆地浮标不发鱼、不加熟练度。河流引用复用缓存，搜索不反复全场景扫描。

验证：Unity编译通过；实际RPG2地图2432次四方向测试，1172次有效水面落点，1260次拒绝；禁用水面组件后拒绝抛竿。结果 Logs/FishingWaterChecks.txt。保留现有UI和素材。
