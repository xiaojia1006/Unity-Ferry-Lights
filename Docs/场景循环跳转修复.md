# 场景往返循环修复（2026-11-25）

根因：在SceneChanger触发区内保存离开场景时的位置，后续返回时SaveSystem恢复该位置，再次OnTriggerEnter自动反向传送。旧DelayFade还会在卸载原场景前把持久玩家移动到目标坐标，可能触发原场景其它触发器。
