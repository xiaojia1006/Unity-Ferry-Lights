# StatsCanvas 属性组件修复（2026-11-24）

定位：旧 StatsUI 在十个属性格子上仍写死 statsSlots[0]=攻击、statsSlots[1]=移速，和新中文属性布局冲突。StatsPanelBinder 又扫描全局中文前缀，导致两个刷新来源覆盖彼此，并可能修改其它 UI 的说明文字。

修复：StatsUI 按格子已有的精确属性标签绑定，不按数组顺序；统一使用 PlayerStats.Value。Binder 只刷新 StatsUI 所引用的格子，取消全局文本扫描。兼容旧 Damage/Speed 标签、非激活子文字、空格子与空玩家；启动时隐藏属性面板并关闭射线阻挡；打开时使用原 MenuPause 暂停流程。生命显示当前/上限，攻击显示夜间修正后的实际值。

验证：运行时和编辑器程序集编译通过。Unity 内 StatsPanelChecks 通过格子换序、隐藏标签、空引用、旧标签、当前/最大生命、有效攻击力、非属性说明隔离和无玩家处理检查。结果 Logs/StatsPanelChecks.txt。没有修改场景布局、物品配置或奖励。

2026-11-24 UI约束：属性格子保留原有布局、字体、底图、尺寸；移除钓鱼/烹饪/声望括号长说明，统一紧凑“属性:数值”。实际熟练度和声望效果继续在逻辑层生效，不往原有格子里塞说明。
