# 属性与场景任务对应关系（2026-11-24）

## 实际生效

- 生命：StatsManager.currentHealth/maxHealth，受战斗、食物、营火恢复影响，面板显示当前/上限。
- 攻击：近战 StatsManager.damage 经 NightCombat2D 修正；弓箭按箭矢基础伤害经相同夜间规则。近战面板显示有效攻击。
- 移速：角色移动读取 StatsManager.speed，冲刺乘1.55、超重乘0.85、涉水使用现有水面倍率。
- 体力：冲刺每秒消耗26，不冲刺每秒恢复14，上限100；登录/切换账号和重新运行时重置。
- 负重：真实背包件数；默认上限20，声望每级+2，上限26。超过上限触发现有15%减速。
- 钓鱼：仅成功收到鱼入背包才+1，提前拉竿/满背包不增长。每10条升一级，咬钩窗口每级+0.1秒，最多+0.5秒。
- 烹饪：RPG2成功熬汤、Willowreach成功帮厨各+1；每5份一级。RPG2蘑菇汤/南瓜汤使用时每级额外恢复1生命，最多+5，不修改共享ItemSO资源。
- 声望：不同委托成功发奖后计数，完成1/3/4种委托升到1/2/3级，直接提升负重上限。稳定任务ID防止反复交互和重进场景刷声望。
- 射程、击退：对应 StatsManager.weaponRange/knockbackForce，近战命中范围和击退调用直接使用；它们不是每个任务都自动增加。

## 任务ID

RPG2.quest.0：热汤；quest.1：修桥；quest.2：三灯；quest.3：遗迹；RPG2.sheep：救羊。
RPG1.frontier：伐木场重启。
Willowreach.delivery.0/1/2：三次运货；Willowreach.runes：符石；Willowreach.pasture.<节点名>：草场。
Legacy.<场景>.<任务资源名>：旧 QuestManager 委托。

奖励继续沿用各任务现有的金钱、经验、物品配置；不把全部任务武断改成直接加攻击/生命。

## 存储范围

钓鱼次数、烹饪次数、完成的独立任务及声望按 LoginSession.Account 写入本机 PlayerPrefs 的v2键。访客单独记录，不复制旧的设备共享统计给任意账号；旧键保留未删除。设置仍是设备共享。

现有地图机关、采集点、任务奖励领取标记仍是本次运行/场景状态，本次未实现整套任务/背包/等级磁盘存档。不同任务的首次声望按账号持久防重，但重进场景仍可重玩原任务并获得原有当局奖励。

## 修复

修桥先验证奖励容量，再消耗木料；满包不会吞掉三捆木料。烹饪和声望不再只是无效果的计数。统计补到其他场景成功结算处；账号切换不会继承别人的熟练度与声望。
