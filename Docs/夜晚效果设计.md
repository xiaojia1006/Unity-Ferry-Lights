# 夜晚效果设计方案（A 版原型）

目标：在 **RPG2 苇岸渡口** 验证"手绘素材压暗后好不好看"，同时让三盏灯、营火在夜里获得视觉回报。不做全局昼夜循环，不改玩法逻辑。

---

## 1. 现状核对（动手前必须知道的事实）

| 项 | 现状 | 对方案的影响 |
|---|---|---|
| 渲染管线 | Built-in RP，**未装 URP，无 Light2D** | 不用 2D 光照，改用"屏幕染色 + 叠加光斑" |
| 自定义 shader | `Assets/Sprites/Water/` 下 5 个（PixelWater / PixelRain / PixelSnow / WinterSurface / SnowFootprint） | 迁 URP 要重写这些，否决 |
| 天气 | `WeatherCycle2D`，Sunny/Rain/Snow，45–100 秒随机，6 秒过渡，暴露 `RainAmount` / `SnowAmount` | 夜晚可与之叠加，取它的强度做补偿 |
| 互动节点 | `RPG2Point`，25 个，枚举含 `Camp`(营火) / `Beacon`(三盏灯) / `Treasure` / `Inn`，且已有 `glow` 字段和 `SetLit(bool)` | 光源可以**自动注册**，不用改场景和预制体 |
| UI 画布 | 背包 `sortingOrder 100`，RPG2 HUD `130`，全局设置 `32000` | 夜层放 **50**，天然在所有 HUD 之下 |
| 全局设置 | 已有 `GlobalSettings.cs`（PlayerPrefs 键 `Rpg.GlobalSettings.v1`，Esc/F10 打开，含音频/画面/操作/游戏/账号/关于六页） | 夜间开关未来挂在"画面"页，不新建设置系统 |
| 暂停 | `MenuPause`（多 owner 引用计数） | 夜晚**不暂停**，不占用它 |

> 备注：此前口述"工程没有设置界面"是误判，`GlobalSettings.cs` 已存在且相当完整，本方案直接复用。

## 2. 时间轴与曲线

一个昼夜 8 分钟，A 版默认从白天开始（不强制玩家等天黑）：

| 相位 | 时长 | 染色 alpha | 说明 |
|---|---|---|---|
| Day 白天 | 180s | 0.00 | 原样 |
| Dusk 黄昏 | 60s | 0 → 0.28 | 色相偏暖 `#2A1B12` 轻微叠加 |
| Night 夜晚 | 180s | 0.28 → 0.50 | 色相 `#0A1A2E` 蓝青 |
| Dawn 黎明 | 60s | 0.50 → 0 | 偏暖回白 |

曲线用 `Mathf.SmoothStep(0,1,t)`，避免线性带来的"匀速变暗"机械感。
**强制上限 0.50**：手绘素材带白天烘焙光影，超过 0.5 会发灰、脏。

调试用 `F9` 键循环切换 白天 → 黄昏 → 深夜 → 黎明，方便肉眼比对（正式版保留，藏在开发键里）。

## 3. 渲染分层

新建一个常驻 Canvas（只建一次，跟随场景）：

| 层 | 类型 | sortingOrder | 内容 |
|---|---|---|---|
| 世界 | SpriteRenderer | 0–99 | 地形、水面、树木、角色、守卫（原样，不改） |
| 夜幕染色 | Canvas + Image | **50** | 全屏纯色 `#0A1A2E`，alpha 由曲线驱动 |
| 暗角 | 同 Canvas 子物体 | 50 | 径向渐变贴图（中心透明 → 边缘 0.45），铺满屏幕 |
| 光源 | 世界空间 SpriteRenderer | 排序高于角色 | 叠加材质（Particles/Additive）的柔光圆斑 |
| HUD | Canvas | 100 / 130 / 32000 | 背包、委托、提示、小地图、设置 —— **全部不参与染色** |

关键点：**光源用世界空间 SpriteRenderer，不用 Canvas**。这样光斑跟着营火/灯/角色走，还能被 Y 轴排序管理，不需要每帧算屏幕坐标。

---

## 4. 光源注册（零改场景）

`DayNight2D.Awake()` 里 `FindObjectsOfType<RPG2Point>()`，按 `kind` 自动挂光斑：

| 节点 | 光斑半径 | 颜色 | alpha 上限 |
|---|---|---|---|
| `Camp` 营火 | 3.2 单位 | `#FFB96B` 暖橙 | 0.55 |
| `Beacon` 三盏灯 | 2.0 单位 | `#FFD79A` | 0.50（只在 `SetLit(true)` 后启用） |
| `Inn` 旅舍窗口 | 1.6 单位 | `#FFC98A` | 0.40 |
| `Treasure` 遗迹 | 1.4 单位 | `#C9E6B0` 微绿 | 0.35 |

- 光斑用统一贴图 `light_soft.png`（512²，中心白 → 边缘透明），缩放到目标半径；
- 材质 `Sprites/Default` 换成 additive，避免"贴一张灰圆片"的廉价感；
- 三盏灯复用 `RPG2Point.glow` 的启用状态：`glow.activeSelf == true` 才亮，**不新增任务状态**；
- 玩家自身不给光（A 版），保证"黑暗有压迫感"。

## 5. 夜里必须有回报（否则纯变暗 = 负体验）

A 版只做三条，成本极低：

1. **点灯反馈强化**：夜里点亮信标时，在背景加 0.15 秒全屏提亮（alpha 瞬降 0.12 再回），像"火光一闪"。
2. **营火存在感**：夜里营火光圈最亮，配合"12 点生命恢复"，玩家会主动想回去。
3. **夜晚专属音**：进入 Night 时切 `Continue_Life`（遗迹内切 `Lightless_Dawn`），黎明切回白天曲 —— 音乐素材已备好（`Assets/Audio/BGM`）。

> 夜鱼、萤火虫、守卫夜间减速等玩法改动 **放到 B 版**，A 版不碰玩法数值。

---

## 6. 与现有系统的衔接

- **天气**：雨夜 alpha `+0.05`（"雨夜更沉"），雪夜 `+0.03` 且光斑颜色偏冷 `#FFEAD0`；白天不下雨时正常。
- **音乐**：只做"切歌判定"，不写播放器 —— 复用 `GlobalSettings` 里已有的 `music` AudioSource 与 `Data.music` 音量，避免两套音频打架。
- **设置**：B 版在 `GlobalSettings` 的"画面"页追加"夜间变暗"开关（`Preferences` 加一个 bool，注意 `StorageKey` 版本号已是 v1，新增字段 JsonUtility 兼容旧存档，不必升版本）。
- **暂停**：夜晚不改变 `Time.timeScale`，与 `MenuPause` 无交集。

## 8. DayNight2D 骨架

```csharp
public sealed class DayNight2D : MonoBehaviour
{
    public enum Phase { Day, Dusk, Night, Dawn }
    // 时长（秒）
    public float daySeconds=180, duskSeconds=60, nightSeconds=180, dawnSeconds=60;
    public float maxDarkness=0.5f;      // 硬上限
    public Color nightTint=new Color32(10,26,46,255);
    public bool  enableAtmosphere=true; // 未来设置开关接这里

    public Phase Current { get; private set; }
    public float Darkness { get; private set; }  // 0..maxDarkness，供外部读取
    public static DayNight2D Instance { get; private set; }

    // 内置：创建 Canvas(sortingOrder=50) + 两层 Image + 光源注册
    // Update：推进相位 → SmoothStep → 设置 tint alpha / 光斑 alpha
    // F9：CyclePreview()  强制切到下一相位
    public void CyclePreview();
    public void SetPhase(Phase phase, bool snap=true);
}
```

外部只需要读 `DayNight2D.Darkness`（如果以后要让守卫在夜里减速，直接乘这个值即可）。

## 9. 可读性红线（不可妥协）

1. 守卫红色预警、交互提示、小地图、委托 HUD **一律不变暗**（靠 sortingOrder 50 保证，不靠手动排除）。
2. 深夜 alpha 上限 0.50，**任何调参都不能突破**。
3. 光斑叠加不能过曝：alpha ≤ 0.55，颜色偏暖不偏白，浅色地面（雪地）单独降到 0.35。
4. 水面 shader 会被全屏染色一起压暗，这是预期效果，不要给水面单独提亮。

## 10. 验收清单

- [ ] F9 循环四相位，肉眼确认过渡平滑无跳变
- [ ] 夜里站在告示牌旁，委托提示和 "R 委托" 按钮清晰可读
- [ ] 夜里被守卫追击，红色预警仍然醒目
- [ ] 三盏灯点亮后，夜里光斑明显、白天几乎看不出
- [ ] 营火光圈在深夜最强，走远后自然衰减
- [ ] 与雨/雪天气叠加时没有发灰、没有闪烁
- [ ] 帧率与改动前一致（两张全屏 Image + 5 个 sprite，应无可见开销）
- [ ] 切场景再回来，相位重置为 Day，无残留 Canvas

## 11. 风险与调参档位

| 风险 | 表现 | 处置 |
|---|---|---|
| 手绘素材压暗发脏 | 草地/树木糊成一团 | 先比 0.35 / 0.45 / 0.50 三档，取观感最好的一档并把上限写死 |
| 暗角过重 | 边缘看不清，像镜头脏 | 暗角上限 0.45，且中心 40% 区域完全不压 |
| 光斑过曝 | 营火周围一片白 | additive alpha 降到 0.35，半径缩小 20% |
| 与天气冲突 | 雨夜双重压暗变黑 | 雨夜补偿 +0.05 后总 alpha 仍受 0.5 上限钳制 |

## 12. B 版（确认好看之后再谈）

1. **全局化**：`DayNight2D` 改 `DontDestroyOnLoad`，各场景用一个 `bool participatesInDayNight` 声明是否参与；登录页不参与。
2. **提灯道具**：占一格背包，扩大玩家光圈，形成"带灯还是省背包"的取舍。
3. **夜间专属内容**：夜鱼（钓鱼稀有）、萤火虫（采集点）、守卫夜间视野缩短但速度不变。
4. **设置项**："夜间变暗"开关进 `GlobalSettings` 的"画面"页。
5. **音频**：接 `AudioManager`，做夜晚/遗迹两套歌单的交叉淡入。
