# 账号存档与流程完善（2026-11-25）

## 使用

成功登录后自动回到该账号最后保存的场景与位置。服务不可连接时，登录提示会明确说明，再按一次原有“进入世界”按钮可用独立的“离线游客”身份试玩；错误密码不会触发游客降级。未新增或改动任何登录/属性/设置画布布局。

RPG2修桥后，北岸(4,8)附近出现“柳湾入口”世界路标，靠近按G前往Willowreach。柳湾(-18,-13)附近路标按G返回。原RPG1/RPG2出口仍可使用。

## 保存范围

- 按账号分别保存当前场景、位置、生命/最大生命、基础攻击/速度、射程、击退、体力、金币、背包槽和等级经验。
- RPG2接取状态、四条主委托完成状态、已采集点、桥、信标顺序/灯光、宝藏、救羊、日记计数和昼夜相位时间。
- RPG1供能与结算状态，已击败敌人；柳湾节点完成状态、运货已结算次数/待领奖状态、符石完成状态、骨笛和烹饪次数。
- 旧QuestManager已接取/已完成任务引用。
- 宝箱开关及地面尚未拾取的物品，防止宝箱重置刷奖励。

每2秒自动保存；场景互动通知、物品变更和战斗触发帧末检查点；切场景、登出、正常退出和应用进入后台保存。文件写入采用临时文件替换，并保留.bak备份。进程被强制终止仍可能丢失最近少量尚未写入的状态。

存档目录：Application.persistentDataPath/Saves。文件名为账号SHA256摘要，不直接使用账号拼路径；不存密码或登录令牌。按账号的熟练度/声望仍沿用PlayerStats的PlayerPrefs键，不迁移旧设备共享计数。

## 生命周期修复

钓鱼对象OnDisable/OnDestroy都恢复原Sprite/Animator；RPG2退出与场景传送、登出明确收竿。

临时增益登记独立撤销操作：禁用/销毁时停止协程并恢复基值、释放速度层数。存档扣除未到期增益，读档/跨场景恢复基础属性并结束临时增益，避免把限时效果固化成永久属性。临时增益剩余时长目前不跨读档保存。

修桥完成后文字显示“木料已交付 · 渡桥已修复”。宝藏完成时使用现有提示显示本章完成。F11/F12仅开发构建启用。

## 稳定引用与备份

新增SaveIdentity保存固定GUID，给场景内需要记录的物体加组件，不更改UI布局。物品/旧委托使用Unity资产GUID目录，不用物品显示名称或GetInstanceID。

新增物品后运行Tools/RPG/Save/Refresh Item Catalog。新增需要保存的世界节点应赋予唯一SaveIdentity.id；现有三个场景已安装。安装时原场景磁盘/编辑器现场备份在Backups/SaveSetup-*，最近路径见Backups/LatestSaveSetup.txt。

## 当前边界

进行中的钓鱼、烹饪动作、运货倒计时与战斗动画不会原帧恢复，读档回到稳定状态；已获得的物品/已完成奖励和运货待领奖状态保留。没有云存档，没有跨设备同步。存档结构版本1，未来修改任务结构时需做迁移。位置恢复沿用现有2D碰撞，不使用3D物理。

运行回归日志：Logs/SaveRegressionChecks.txt。检查使用随机测试账号，清理测试存档，退出Play Mode，不覆盖用户账号文件。
