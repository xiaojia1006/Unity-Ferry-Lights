# 音频素材使用说明

放置位置：`D:\unity\Rpg\Audio\`（同时已复制一份到 `Assets\Audio\`，Unity 只会导入 Assets 下的文件）

```
Audio/
├─ BGM/        10 首背景音乐 (mp3)
├─ SFX/
│   └─ 80-CC0-RPG-SFX/   80 个音效 (ogg)
├─ Ambience/   雨声循环 + 雨夜雷声 (ogg)
└─ LICENSES.txt  来源与授权（必读，CC BY 的曲目需要署名）
```

## 二、Unity 导入设置建议（选中文件后在 Inspector 改）

**BGM（mp3）**
- Load Type: `Streaming`（不占内存，长曲子必选）
- Load In Background: ✔
- Compression Format: `Vorbis`，Quality `0.6 ~ 0.7`
- Force To Mono: ✘（保留立体声）

**SFX（ogg）**
- Load Type: `Decompress On Load`
- Compression Format: `Vorbis`，Quality `0.8`（短音效也可用 PCM 换精度）
- Force To Mono: ✔（省内存，2D 游戏无方位需求）

**Ambience（ogg）**
- Load Type: `Streaming`，Load In Background: ✔
- 在 AudioClip 上勾 `Loop`，或代码里 `source.loop = true`

## 三、接到代码里

1. **雷声终于有素材了**：`RainFootsteps2D.thunder` 现在是空数组，把 `Dark_Rainy_Night.ogg`（或从中截一段）拖进这个数组，打雷逻辑立刻生效。
2. **雨声层**：新建一个常驻 AudioSource 播放 `amb_rain_loop_1.ogg`，音量用现成的 `weather.RainAmount` 驱动，与 `RainFootsteps2D` 里 `thunderVolume * weather.RainAmount` 的写法保持一致。
3. **BGM 切换**：建议写一个 `AudioManager`（DontDestroyOnLoad + AudioMixer 的 Master/Music/SFX 三条），切场景时 0.8~1.5 秒交叉淡入淡出，不要硬切。
4. **交互反馈（当前最缺的）**：
   - 按 E 拾取 → `item_misc_01~03.ogg`
   - 金币入袋 → `item_coins_01~02.ogg`
   - 木料 / 石头 → `item_wood_*` / `item_stone_*`
   - 开委托手册 → `book_01~04.ogg`
   - 开宝箱 / 解锁 → `lock_01.ogg`
   - 守卫受击 / 死亡 → `creature_hurt_01` / `creature_die_01`
   - UI 按钮（暂时没有专门 UI 音）→ 用 `book_01` 或 `misc_01` 顶替，之后可换 Kenney Interface Sounds
